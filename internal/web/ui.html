OpenCode Go 密钥管理

CLIProxyAPI 插件 cliproxyapi-opencode-provider

当前页面既非 HTTPS，也不是本机地址，出于安全考虑已禁用全部密钥操作。请改用 HTTPS，或在本机（localhost / 127.0.0.1 / [::1]）打开本页面。

1. 管理认证

输入 CPA 管理密钥（management key）。该密钥仅保留在当前页面的输入框中，不会写入浏览器存储、Cookie 或 URL，也不会被记录或回显。

远程访问需在 CPA 中启用远程管理（remote management）；密钥错误多次可能导致当前 IP 被临时封禁，本页面不会自动重试认证。

2. 导入 OpenCode Go 密钥

每行一个 OpenCode Go 密钥。首尾空白会被去除，重复项会被忽略；最多 100 行，每行不超过 4096 字符，单次请求体不超过 64 KiB。请勿在此粘贴 CPA 管理密钥或下游 API key。

密钥仅随本次导入请求发送；导入成功后输入框会被清空，失败时会保留内容以便修改。

用于在 CPA 中区分这批密钥，最长 128 个字符。

运行说明

  • 凭据池化、故障转移与会话亲和由 CPA 负责；插件不实现密钥选择、冷却、重试或健康检查调度。
  • 如需会话亲和，请在 CPA 配置中启用 routing.session-affinity: true。
  • 密钥保存在 CPA 的 auth 目录（auth-dir）中，不保存在浏览器里。
  • 请求头中的会话范围由 CPA 的会话身份与所选 auth 确定性地决定。
